# sts2-notes

杀戮尖塔 2 的规则与数值整理，包含一份说明文和一个从游戏本体抽出的地图生成器。

内容来自对游戏本体的反编译分析，仅供个人参考。仓库不包含任何反编译出来的游戏源码。

## 目录结构

```
sts2-notes/
├── 杀戮尖塔介绍.txt        规则与数值平衡说明
└── mapgen/
    ├── sts2_map.py         地图生成器
    ├── sts2_map.json       生成器配置，首次运行会自动生成
    └── examples/
        └── map_12345.mmd   示例输出
```

## 说明文

`杀戮尖塔介绍.txt` 描述标准模式下的规则骨架与数值模型，覆盖战斗回合流程、牌堆与能量、伤害结算、卡牌稀有度与费用曲线、升级与附魔、关键字、状态体系、角色设计、遗物、药水、地图与房间生成、事件、休息点、战斗奖励、商店与经济、敌人强度、各幕递进、首领轮换、飞升难度，以及卡牌、遗物与状态之间的联动模型。

所有数值取自程序内的常量、枚举与配表，反映的是设计者写在代码里的意图与上限，不等同于实际游玩体验。

## 地图生成器

按反编译源码中的算法重建单幕地图：xoshiro256\*\* 随机数、七列网格上的七条路径、按配额与规则分配节点类型、重复路径段的剪枝与修复，以及居中、撑开、拉直三步后处理。给定同一种子必得同一张图。

```
python sts2_map.py --seed 12345          # 写出 map_12345.mmd
python sts2_map.py 12345 --print         # 同时打印到终端
python sts2_map.py --act 2 --out a.mmd   # 改标题与输出名
python sts2_map.py                       # 不传种子时用配置里的 seed
```

输出是 Mermaid 流程图，可以直接贴进支持 Mermaid 的编辑器，也可以用 `mmdc` 渲染成图片。

### 配置

配置默认在脚本同级的 `sts2_map.json`，不存在时自动生成一份默认配置，默认值就是原作第一幕的参数。节点类型的频率有三种写法：

- `count` 固定个数
- `roll` 高斯抽样个数，用于还原原作里数量随机的那几类节点
- `weight` 权重，按权重瓜分固定个数没有占满的空位

三者都不写的节点只由 `fixed_rows` 或 `default_type` 决定。`rules` 一节的六个开关分别对应原作里的上下段禁用类型、不能相邻重复的类型、不能互为兄弟的类型，以及可以无视规则的类型。

### 与原作的差异

生成器忠实还原了算法，但有两点与游戏内的实际结果不完全一致。原作的地图随机数种子由运行种子加上幕名字的哈希派生，这里直接把传入的种子当随机数种子用。另外剪枝阶段存在删除操作，C# 的 HashSet 在删除后枚举顺序会受空闲槽复用影响，所以节点的处理顺序在极端情况下可能与原程序有细微出入。同种子同输出这一点不受影响。
